What is it worth, and how sure are you?

A valuation workshop that shows its reasoning: where each number came from, which assumptions carry the result, and what the market price already assumes.

Collect

Run the Python collector in Google Colab. It retrieves available annual filings from SEC EDGAR, prices and statements from Yahoo Finance, and macro series from FRED, then scores the data it found.

Import

The collector writes one file, TICKER_dashboard.json. Import it here. Everything after that runs in your browser; nothing is uploaded anywhere.

Interrogate

Read the briefing, move the assumptions, and see which ones matter. Snapshots from the previous studio version still open.
